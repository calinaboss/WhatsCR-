WhatsCR Developer API

Programmatic access to our copyright-free audio catalog.

Endpoint Overview

You can query audio tracks and search by keyword or genre using our JSON REST API:

GET /api/tracks?q={search_term}&genre={genre}

Response Format

The endpoint returns a JSON array containing track metadata including title, artist, audio stream link, duration, and license details.
