## 🌟 About the Project

**WhatsCR?** solves the common headache creators face when searching for copyright-free background music and audio assets. Instead of standard generic music libraries, WhatsCR focuses on curated, loop-ready, and strike-free tracks tailored for indie games, streaming, and creative projects.

## ✨ Key Features

- **Dynamic Hero Search**: Instant search interface with background slideshow.
- **Game-Ready Genres**: Filtered categories for Gaming, Chiptune 8-Bit, Lo-Fi, Cinematic, and SFX.
- **Built-in Audio Player**: Preview audio directly on the page with animated waveforms.
- **One-Click Downloads**: Direct download links for tracks without paywalls or forced logins.
- **Lightweight & Optimized**: Fast load times with next-gen `.webp` assets and Font Awesome 6 icons.

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/calinaboss/WhatsCR-.git
   ```
2. **Open locally:**
   Double click `index.html` or launch with VS Code Live Server.

## 🤝 Collaboration Workflow

When working together on this repository:

1. **Pull the latest changes** before starting work:
   ```bash
   git pull origin main
   ```
2. **Create a feature branch** for new features:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Commit and push your branch:**
   ```bash
   git add .
   git commit -m "feat: describe your change"
   git push origin feature/your-feature-name
   ```
4. **Open a Pull Request (PR)** on GitHub to merge into `main`.
