1. CORE DESIGN PHILOSOPHY
================================================================================
- Clean, Minimalist, High-Trust: The UI should feel like a premium, modern SaaS 
  or creative platform (similar to Spotify, Linear, Stripe, or Vercel).
- Breathable & Light: Pure white (#ffffff) or ultra-soft slate (#f8fafc) surfaces 
  with subtle 1px border lines (#e2e8f0). No harsh gradients, heavy black boxes, 
  or loud clashing colors.
- Micro-Interactions: Smooth transitions (0.2s ease) on hover and micro-scaling 
  (scale 0.98 - 0.99) on active press for a tactile, responsive feel.
- Zero Clutter: Clean information hierarchy with concise, professional labels.

================================================================================
2. THE ZERO-EMOJI RULE & ICONOGRAPHY
================================================================================
CRITICAL MANDATE:
NEVER use default Unicode / system OS emojis anywhere in the UI or code 
(e.g., NEVER use 🎵, 🔥, 🚀, 💡, ❌, ✅, ⚠️, 👤, 🎧, 🔍). 
Default emojis look unprofessional, render inconsistently across Windows, iOS, 
and Android, and break minimalist design aesthetics.

ALWAYS USE: FontAwesome 6+ (Free CDN)
Include in <head>:
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css" crossorigin="anonymous" referrerpolicy="no-referrer">

8. MOBILE TOUCH & ACCESSIBILITY RULES
================================================================================
1. Minimum Touch Targets: Every interactive element (button, link, input, tab) 
   must have at least `min-height: 44px;` and `min-width: 44px;` on mobile screens.
2. Form Input Zoom Prevention: On iOS Safari, inputs with font sizes below 16px 
   trigger auto-zoom. Always use `font-size: 1rem;` (16px) or `0.95rem;` with 
   `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.
3. No Horizontal Scroll: Every container must respect `overflow-x: hidden;` and 
   `max-width: 100vw;`. Never hardcode fixed pixel widths wider than 300px on mobile.
4. Smooth Gestures: Interactive viewports (image croppers, carousels, maps) must use 
   `touch-action: none;` to enable smooth 1-finger panning and 2-finger pinch zooming 
   without browser page-scroll interference.
